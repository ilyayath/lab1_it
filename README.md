# TabDB

Лабораторна з інформаційних технологій: проста система керування табличними
базами даних на Python (система типу 1).

Мій варіант — типи `complexInteger` і `complexReal` та перетин таблиць.

## Що вміє

- створювати бази даних і таблиці з полями типів integer, real, char, string,
  complexInteger, complexReal;
- додавати, редагувати й видаляти рядки, значення перевіряються за типом поля;
- зберігати базу у файл `.tdb.json` і відкривати її;
- знаходити перетин двох таблиць з однаковою структурою.

## Запуск

Десктоп-версія (потрібен лише Python 3.11+):

```
python main.py
```

Сервер, веб-версія і режим клієнта:

```
pip install -r requirements.txt
python server.py
```

Після цього:

- веб-версія — http://127.0.0.1:8000/
- документація API — http://127.0.0.1:8000/docs
- десктоп як клієнт сервера — `python main.py --server http://127.0.0.1:8000`

Бази на сервері зберігаються в папці `data/`.

## Як вводити значення

| Тип | Приклади |
|---|---|
| integer | `42`, `-7` |
| real | `3.14`, `3,14`, `-1e-3` |
| char | `A` (один символ) |
| string | будь-який текст |
| complexInteger | `3+4i`, `5i`, `-i`, `7` |
| complexReal | `3.5-0.25i`, `0.5i`, `1e-3+2i` |

## Приклад перетину

Відкрити `examples/sensors.tdb.json`, далі «Операції → Перетин таблиць…» і
вибрати `Sensors_A` та `Sensors_B`. У результаті будуть рядки з id 101 і 102 —
вони є в обох таблицях.

## Тести

```
python -m unittest discover -s tests
```

## Що де лежить

```
main.py          запуск десктоп-версії
server.py        запуск сервера
tabdb/           код програми
  datatypes/     типи полів
  core/          база, таблиця, поле, рядок
  operations/    перетин таблиць
  storage/       збереження у JSON
  service/       DatabaseService
  gui/           вікна на tkinter
  api/           REST API
  client/        підключення десктопу до сервера
web/             веб-версія
tests/           тести
tabdb_uml/       UML-діаграми
docs/screens/    скріни для звітів
examples/        приклад бази
```

Звіти: `Етап1_UML-специфікація.docx`, `Етап2_Десктоп-версія.docx`,
`Етап3_Веб-версія.docx`, `Етап4_Порівняльний-аналіз.docx`.
