# UML-діаграми проєкту TabDB (PlantUML)

Система: часткова реалізація СУБД табличних баз даних на Python.
Варіант: додаткові типи complexInteger і complexReal, операція перетину таблиць.

## Як відкрити й експортувати

- Онлайн: вставити вміст файлу на https://www.plantuml.com/plantuml або https://www.planttext.com,
  потім завантажити PNG чи SVG.
- VS Code: розширення «PlantUML» (jebbs). Потрібні Java і Graphviz або рендеринг
  через сервер PlantUML у налаштуваннях розширення. Попередній перегляд: Alt+D.
- PyCharm / IntelliJ: плагін «PlantUML Integration».

## Підказки для редагування

- Рядки, що починаються з апострофа ('), є коментарями.
- Розташуванням керують напрямки у зв'язках: -up-, -down-, -left-, -right-.
- Колір елемента задається після його оголошення, наприклад: class Foo #E2F3E6.
- У діаграмах послідовності "++" активує лінію життя, "--" завершує активацію.

Файли написано без локального рендерингу (PlantUML не був доступний під час
створення). Якщо рендерер покаже помилку, він вкаже номер рядка.

## Папка png

Зображення діаграм, вставлені у звіт. Їх намальовано окремим рендерером за тим самим змістом,
що й у .puml-файлах. Після редагування .puml можна експортувати PNG із PlantUML і замінити
рисунок у Word (правою кнопкою на рисунку → «Змінити рисунок»).
